## 📋 نبذة عن المشروع

**الدفتر الذكي** تطبيق يحوّل جهازك إلى دفتر حسابات رقمي متكامل: سجّل عملاءك، تابع الدين والدفع، اعرف صافي الأرباح لحظة بلحظة، وكل البيانات محفوظة على جهازك بدون إنترنت — مناسب للتجار والمحلات الصغيرة.

## 📋 About

**Smart Book** turns your phone into a complete digital ledger: register customers, track debts & payments, and see your net profit in real time. All data is stored locally on your device — perfect for shops and small businesses.

## ✨ Features | المميزات

- 👥 Customer management & profiles | إدارة العملاء وملفاتهم
- 💰 Debt & payment tracking (give / take) | تتبع الدين والدفع
- 📊 Smart dashboard with totals | لوحة متابعة بأرقام إجمالية
- 🧮 Money math engine | محرك حسابات مالية دقيق
- 📜 Full customer history | سجل كامل لكل عملية
- 📶 Works offline | يعمل بدون إنترنت

## 🛠 Tech Stack

`Flutter` · `SharedPreferences` · `Google AdMob` · `Connectivity Plus`

## ⬇️ Download & Run | التحميل والتشغيل

```bash
git clone https://github.com/Zuhairibrahim/sharedpreferences.git
cd sharedpreferences
flutter pub get
flutter run
```
